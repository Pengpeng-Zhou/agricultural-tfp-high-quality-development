# 农业全要素生产率与经济高质量发展：数据、代码与复现材料

本仓库整理了论文《农业全要素生产率对经济高质量发展的驱动机制与空间效应》的代码、数据、实证结果和 LaTeX 稿件。研究样本为中国大陆 31 个省级行政区 2016—2020 年平衡面板，共 155 个省份—年份观测。最新英文投稿包和新增模型结果已同步到 `论文LaTeX_调整版/MDPI_template_ACS/` 及 `结果/英文图表_投稿版/`。

> 仓库默认按未发表研究材料管理。原始统计资料的再分发与正式引用，应遵守《中国统计年鉴》《中国农村统计年鉴》、CNKI 及原数据提供方的使用要求。

## 研究内容

研究考察农业全要素生产率（TFP）对经济高质量发展的作用，主要分析包括：

1. 高质量发展综合指数构建与 DEA—Malmquist 农业 TFP 测算；
2. 省份和年份双向固定效应基准回归；
3. 核密度估计与东、中、西部动态分布比较；
4. Dagum 基尼系数及区域内、区域间净差异和超变密度分解；
5. 全局 Moran's I、局部 Moran（LISA）与空间集聚识别；
6. 缩尾、剔除直辖市、滞后解释变量、水平值和 Driscoll—Kraay 标准误等稳健性检验；
7. 一期滞后农业 TFP 内部工具变量的 2SLS 检验；
8. 空间杜宾模型及直接效应、间接效应和总效应分解；
9. 人均 GDP 单门槛模型；
10. 无条件与空间条件马尔科夫链。

## 核心变量

| 变量 | 含义 | 处理方式 |
|---|---|---|
| `y_clean` | 修正后的经济高质量发展综合指数 | 2016—2020 年样本内标准化并按混合权重合成 |
| `ln_y_clean` | 高质量发展指数自然对数 | `ln(y_clean)` |
| `cum_tfp` | 累计农业全要素生产率 | 五投入 DEA—Malmquist，2016 年统一为 1 |
| `ln_cum_tfp` | 累计农业 TFP 自然对数 | `ln(cum_tfp)` |
| `pop_density` | 人口密度 | 常住人口/行政区域面积 |
| `ln_pop_density` | 人口密度自然对数 | `ln(pop_density)` |
| `primary_share` | 第一产业增加值占 GDP 比重 | 回归控制变量 |

完整字段定义见 [`说明/05_变量字典.csv`](说明/05_变量字典.csv)，逐项数据来源见 [`说明/06_数据来源索引.csv`](说明/06_数据来源索引.csv)。

## 数据来源与处理说明

- 高质量发展二级指标来自 `Y原始指标_data_for_res.xlsx`；随包材料未标明每个指标对应的年鉴、表名和页码，正式投稿前仍需作者补齐来源。
- 城镇化率、人口密度和第一产业占比来自 `控制变量.xlsx`。
- 农业机械总动力、化肥、塑料薄膜、柴油、农药和农林牧渔业总产值主要依据《中国统计年鉴》《中国农村统计年鉴》相关地区表，部分表由 CNKI PDF 版面识别整理。
- TFP 保留原研究方案的五项投入：农业机械总动力、化肥、农用塑料薄膜、农用柴油和农药；产出为当年价农林牧渔业总产值。
- 2016 年累计 TFP 被设为共同基期 1，因此该年横截面差异为 0，不能将其 Dagum 基尼或空间马尔科夫结果解释为绝对生产率水平差异。

## 软件环境

- Python 3.11 或更高版本；
- 依赖版本见 [`requirements.txt`](requirements.txt)；
- 论文使用 XeLaTeX 编译，建议 TeX Live 2024 或更新版本；
- Windows 下中文图形默认尝试使用 Microsoft YaHei/SimHei，其他系统可在脚本中替换字体。

python -m venv .venv

.venv\Scripts\activate

## 复现顺序

在仓库根目录依次运行：

```bash
python 01_构建完整数据并回归.py
python 02_核密度分析.py
python 03_Dagum基尼分解.py
python 04_扩展实证分析.py
```

脚本 01 会由 `数据/原始数据_只读副本/` 重建分析面板并更新基准回归结果；脚本 02—04 使用 `数据/新构建分析数据.csv`，分别更新核密度、Dagum 分解以及扩展空间计量结果。图表和 CSV/TXT 输出会写入 `结果/` 下对应子目录。

`04_扩展实证分析.py` 使用固定随机种子 `20260903`，涉及 Moran 置换检验、门槛 Bootstrap 和空间马尔科夫独立性检验时可获得可重复结果。

编译最终论文：

```bash
cd 论文LaTeX_调整版
xelatex thesis_adjusted.tex
xelatex thesis_adjusted.tex
```

`05_写入论文扩展章节.py` 和 `06_转换为LaTeX.py` 是本次文稿形成过程中使用的历史工具，依赖本地 Word 模板/中间稿路径。仓库不上传 Word 中间稿；日常复现以已整理好的 `论文LaTeX_调整版/thesis_adjusted.tex` 为准。

## 计量设定与解释边界

- 基准模型控制省份和年份固定效应，标准误按省聚类。
- 空间权重采用省级接壤矩阵并行标准化；为避免孤岛，海南与广东桥接。不同权重矩阵下的稳健性仍可进一步检验。
- 内生性部分采用一期滞后 TFP 作为内部工具变量。排除限制无法被数据完全检验，因此结果属于缓解性证据，不等同于严格因果识别。
- 样本期仅为 2016—2020 年，门槛、局部 Moran 和空间马尔科夫结果可能受小样本影响，应结合稳健性和经济机制谨慎解释。
- 原始产出为当年价指标，未来可进一步进行价格平减并补充土地、劳动、气候等投入变量。
