# 英文投稿图表与结果

本目录保存与 MDPI 英文投稿稿对应的图表、配套数值文件和回归表。文件按论文中的相对路径分为 `figure1/` 和 `figures/` 两组，便于与 `论文LaTeX_调整版/MDPI_template_ACS/template.tex` 对照。

- `figure1/`: 高质量发展指数三维曲面图、累计农业 TFP 热力图、全国与区域核密度图、基准回归表、稳健性图及校验数据。
- `figures/`: Dagum 总体/区域内/区域间分解图、Moran 全局与局部图、耦合协调图、空间影响分解图、门槛轮廓图和配套结果数据。

图表中的累计 TFP 以各省 2016 年为共同基期并设为 1；2016 年累计 TFP 没有横截面差异，因此不绘制其密度曲线和 Moran 统计量。具体公式和模型定义见 `论文LaTeX_调整版/MDPI_template_ACS/公式与模型说明.md` 及同目录的 `template.tex`。
